# 游戏设计文档：人间悟道

## 引言

《人间悟道》是一款基于抖音小游戏平台的休闲挂机游戏，核心玩法融合了修仙题材与现实生活映射。玩家扮演一位寿终正寝后转生到“休闲界”的灵魂，通过修炼现实世界的知识与技能，在修仙世界中获得力量与成就。游戏强调自主学习、社交互动与对抗“虚无”的主题，旨在让玩家在娱乐中反思现实生活。

游戏目标：通过修炼提升修为，积累道具，赠与其他玩家，共同对抗“虚无”侵袭，最终达成“悟道”境界。

## 设计理念

### 核心理念
- **映射现实与幻想**：将现实生活中的学科（如数学、历史、科学）映射到修仙世界的修炼体系（如术数、修仙史、炼丹术），让玩家在游戏中重温学习乐趣，同时寓教于乐。
- **自主与社交**：玩家可以自主出题、审核、答题，形成社区生态。道具赠送机制促进玩家间互动，增强社交粘性。
- **对抗虚无**：游戏的敌人“虚无”象征内心的空虚与无知，玩家通过修炼知识来对抗它，传递积极的人生价值观。
- **休闲挂机 + 互动**：基础挂机收益 + 答题互动，适合碎片化时间，同时避免纯挂机导致的疲劳。

### 目标受众
- 喜欢修仙题材的玩家
- 希望在游戏中学习知识的用户
- 社交型玩家（喜欢分享、点赞、赠送）
- 休闲玩家（不需高强度操作）

### 价值观
- 鼓励学习与分享：答题系统寓教于乐，赠送道具促进互助。
- 反思现实：通过映射现实，引导玩家思考生活中的“修炼”。

## 游戏设定

### 世界观
玩家前世寿终正寝，转生到“休闲界”——一个介于现实与仙界之间的平行世界。这里，现实世界的知识被映射为修炼资源：
- **数学 → 术数**：计算符咒、阵法威力。
- **历史 → 修仙史**：了解仙界历史，解锁剧情。
- **科学 → 炼丹术**：合成丹药、道具。
- **文学 → 仙文**：撰写符箓、咒语。
- **艺术 → 画符**：绘制符咒、装饰。
- **体育 → 武道**：提升体力、耐力。
- **其他**：可扩展，如编程→符阵编织、音乐→仙乐等。

玩家选择1-3个感兴趣领域进行重点修炼，每个领域有对应的修炼树（升级路径）。

### 敌人：虚无
- “虚无”是一种抽象敌人，象征内心的空虚、无知与消极情绪。
- 表现形式：定期侵袭（事件），如“虚无风暴”降低收益，或“虚无迷雾”隐藏界面。
- 对抗方式：通过答题修炼积累“悟道值”，悟道值越高，对抗力越强。玩家可联合其他玩家共同对抗大型虚无事件。

## 玩法机制

### 核心玩法
1. **挂机修炼**：
   - 基础收益：每秒自动积累“修为”（类似金币）。
   - 升级：消耗修为提升修炼等级，解锁新领域或增强收益。
   - 离线收益：离开游戏后，按时间积累修为（上限24小时）。

2. **答题修炼**：
   - **自主出题**：玩家在选定领域出题（选择题、填空题等），提交后由社区审核（点赞/踩）。
   - **审核机制**：其他玩家审核题目质量，优质题目获得奖励。
   - **答题互动**：每日答题任务，正确率影响修为加成。答对题目可获得“悟道碎片”。
   - **点赞系统**：题目/答案可被点赞，积累“声望值”，用于解锁高级道具。

3. **道具系统**：
   - 修炼产物：不同领域产出道具（如术数符咒、炼丹药剂）。
   - 赠送机制：道具可赠与其他玩家（通过ID或社区），赠送后双方获得“缘分值”，提升社交等级。
   - 使用：道具可用于加速修炼、增强收益，或对抗虚无。

4. **社交与对抗**：
   - **社区**：查看其他玩家题目、排行榜、赠送记录。
   - **联合对抗**：大型虚无事件时，玩家可组队答题，共同积累悟道值。
   - **排行榜**：按修为、声望、赠送次数排名。

### 平衡性考虑
- 挂机收益递减：高等级升级成本指数增长。
- 答题难度：题目难度与玩家等级匹配，避免挫败感。
- 社交激励：赠送道具给予双向奖励，鼓励活跃。

## 架构（技术架构）

### 整体架构
- **前端**：基于抖音小游戏API（tt.*），使用Canvas渲染。
- **模块化**：采用CommonJS模块（require/module.exports），便于扩展。
- **数据存储**：本地存储（tt.setStorageSync），未来可扩展云端。
- **网络**：抖音API用于社交（分享、排行），暂不依赖后端。

### 模块结构
```
src/
├── state.js      # 全局状态（修为、等级、道具、时间戳）
├── logic.js      # 核心逻辑（收益计算、升级、答题判定）
├── storage.js    # 存档/读取、离线收益
├── ui.js         # UI绘制（界面、按钮、动画）
├── question.js   # 答题系统（题目管理、审核、点赞）
├── social.js     # 社交功能（赠送、排行、联合对抗）
├── config.js     # 配置（领域映射、平衡数值）
```

### 数据流
1. 初始化：加载存档 → 计算离线收益 → 启动主循环。
2. 主循环：更新收益 → 渲染UI → 处理输入。
3. 事件：答题触发 → 更新状态 → 存档。
4. 社交：通过抖音API分享题目/道具。

### 性能优化
- Canvas渲染：使用脏区更新，避免全屏重绘。
- 内存管理：题目数据分页加载。
- 广告集成：使用抖音广告SDK，观看广告获得额外收益。

## UI设计概念

### 整体风格
- **主题**：仙侠风，淡雅色调（青绿、紫金），背景云雾缭绕。
- **布局**：竖屏设计（portrait），顶部修为显示，中部修炼界面，底部按钮区。
- **交互**：触摸为主，简单直观，避免复杂手势。

### 主要界面
1. **主界面**：
   - 顶部：修为数值、悟道值进度条。
   - 中部：当前领域选择（图标+进度条），挂机收益动画（飘字效果）。
   - 底部：升级按钮、答题入口、社交按钮。

2. **修炼界面**：
   - 领域树：树状图显示升级路径，点击解锁。
   - 道具栏：展示产出道具，拖拽赠送。

3. **答题界面**：
   - 题目显示：文本+选项，计时器。
   - 审核界面：点赞/踩按钮，评论区。
   - 出题界面：表单输入题目内容。

4. **社交界面**：
   - 排行榜：列表显示玩家数据。
   - 赠送界面：搜索玩家ID，发送道具。
   - 联合对抗：组队界面，实时进度。

### 视觉元素
- **动画**：修为增长飘字、升级特效、虚无侵袭粒子效果。
- **音效**：轻音乐背景，答题正确/错误音效。
- **素材来源**：爱给网（aigei.com），下载仙侠风格图片/音效。

### 响应式设计
- 自适应分辨率：根据tt.getSystemInfoSync()调整元素大小。
- 无障碍：大字体、高对比度，支持语音提示（未来）。

## 变现策略

### 主要变现：广告
- **激励视频**：观看广告加速修炼（双倍收益1分钟）、获得额外道具。
- **插屏广告**：答题后或升级时展示，短时收益。
- **Banner广告**：主界面底部，持续曝光。
- **积分墙**：完成任务观看广告，积累“仙玉”（游戏内货币）。

### 其他变现
- **内购**：未来扩展皮肤、加速道具（但当前以广告为主）。
- **数据变现**：匿名收集玩家学习偏好，用于优化题目。

### 平衡
- 广告不强制：可跳过，但奖励丰厚。
- 频率控制：每日广告上限，避免用户流失。

## 未来扩展与改进想法

### 改进建议
1. **玩法深度**：增加“转生”机制，重置进度但保留部分道具，鼓励长期玩。
2. **社交增强**：引入公会系统，公会成员共享题目库，共同对抗虚无。
3. **教育性**：与现实教育机构合作，提供真实题目，增加学习价值。
4. **平衡调整**：测试挂机与答题的比例，避免纯挂机玩家优势过大。
5. **技术扩展**：引入后端服务器，支持实时多人答题、道具交易。
6. **UI优化**：加入更多动画，如修炼进度条填充、道具合成特效。
7. **素材整合**：从爱给网批量下载素材，分类存储在assets/目录。

### 潜在问题
- **审核机制**：自主出题可能产生低质内容，需AI辅助过滤。
- **对抗虚无**：需设计有趣的事件，避免枯燥。
- **变现依赖**：广告收入波动大，可考虑混合模式。
